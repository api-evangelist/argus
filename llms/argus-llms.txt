# ARGUS (Altus Group)

> ARGUS is Altus Group's suite of commercial real estate software: ARGUS Enterprise
> (property valuation and cash flow forecasting), ARGUS Developer (development
> feasibility), the ARGUS Intelligence Platform (portfolio analytics, asset and fund
> management), ARGUS EstateMaster, ARGUS Taliance and ARGUS Voyanta. Altus Group markets an
> "ARGUS API" integration gateway for cloud-enabled ARGUS solutions.

Generated by API Evangelist on 2026-09-14 from the ARGUS apis.yml record and from live
probes of Altus Group's public surface. Altus Group does not publish an /llms.txt of its
own; every host on the ARGUS estate was probed and none served one.

## What an agent can and cannot do here

ARGUS has **no public API contract**. As of 2026-09-14 Altus Group publishes no OpenAPI,
Swagger, GraphQL SDL, AsyncAPI, Postman collection, WSDL or .proto for any ARGUS product,
at any URL, on any host. There is no developer portal, no API reference, no published base
URL, no rate-limit documentation and no pricing. An agent cannot call ARGUS.

What does exist, and was verified:

- The ARGUS Intelligence Platform front-end calls versioned service prefixes on
  https://platform.altusintelligence.com — /core-service-v1, /backend-v1, /stewardship-v1,
  /mdmapisvc-v1, /derived_domains-v1, /stress-testing-v1. All six return HTTP 403
  "Missing Authentication Token" to anonymous callers. No swagger.json or openapi.json is
  served under any of them.
- Authentication for the ARGUS Intelligence Platform is Microsoft Entra ID, single tenant,
  authorization code with PKCE (S256), EU tenant region.
- The ARGUS support community at https://service.altusgroup.com serves a real OpenID
  Connect discovery document; it authenticates support users, not API consumers.
- Access to the ARGUS API is obtained through an Altus Group customer account and the
  support community, not through self-serve signup.

## Lifecycle deadlines an agent should know

- 2026-05-15 — support ended for ARGUS Enterprise version 13.
- 2026-10 — Citrix delivery ends; the ARGUS Cloud portal can no longer launch the app.
- 2026-12-31 — ARGUS Enterprise version 13 removed from ARGUS Cloud.
- 2027-01-01 — all version 13 cloud access discontinued; ARGUS Intelligence Platform
  authentication becomes mandatory to connect to the database (AE 14.5.0.930 or
  AE 15.0.1.1170 or later required).
- ARGUS Valuation DCF, ARGUS Valuation Capitalisation and ARGUS Asset Management (DYNA) are
  retired and succeeded by ARGUS Enterprise.
